# 🎯 Java Quiz Game

A simple console-based Quiz Game built using **Java**. Test your knowledge by answering questions and enjoy a fun command-line quiz experience!

## ✨ Features
- Interactive quiz experience.
- Multiple questions with answer options.
- Object-Oriented Programming (OOP) concepts.
- Displays questions and evaluates user answers.

## 🛠️ Tech Stack
- Java
